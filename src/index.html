DELTATRANSLATE clone le dépôt, installe le fichier du chapitre sous lang/lang_fr.json. Les sauvegardes restent locales jusqu’au clic sur Publier, qui fusionne les changements, crée un commit descriptif et les envoie sur GitHub. L’accès en écriture utilise uniquement les identifiants Git déjà configurés sur cette machine.

1. UndertaleModTool CLI

Vérification…

Lie une installation existante d'UTMT CLI, ou laisse l'outil télécharger et extraire automatiquement la dernière release officielle adaptée à ton système.

2. Importer un chapitre

Glisse le data.win du chapitre ici, ou ouvre-le manuellement. Les strings, fonts et portraits sont extraits localement : aucun asset du jeu n'est fourni par GitHub. Si lang/lang_fr.json existe, il est édité directement. Sinon, l'outil garde une copie anglaise originale et applique les traductions à la vraie source du chapitre.
