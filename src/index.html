Ton chapitre

Recherche de DELTARUNE dans Steam…

Tu peux aussi déposer un data.win ici Il se trouve dans le dossier du chapitre à traduire.
Où trouver le dossier du jeu ?

Dans Steam, ouvre les fichiers locaux de DELTARUNE depuis le menu Gérer. Sélectionne ce dossier ici : les chapitres qu’il contient seront proposés automatiquement. Pour une autre installation, choisis directement son dossier ou le data.win du chapitre.

Si nécessaire, l’outil de lecture du jeu (UTMT) sera téléchargé automatiquement. Une connexion Internet est alors requise.

Les ressources sont extraites de ta copie du jeu et restent sur ton ordinateur. Aucun fichier de DELTARUNE n’est fourni avec l’application.

Ton chapitre est prêt !

Sélectionne une ligne, écris sa traduction et découvre son rendu dans l’aperçu.

Enregistre avec Ctrl+S (ou ⌘S sur Mac).

Tu peux traduire et sauvegarder localement sans Runedelta ni compte GitHub.

Projet Runedelta

        
        
Désactivée par défaut. Tu peux utiliser le catalogue Runedelta et sauvegarder localement sans publier. Même activée, la publication nécessite un clic sur Publier. Pour masquer Runedelta, décoche son mode dans Chapitre → Fonctions facultatives.

        
Vérification de Git…

        
        
        
        
Choisis une branche existante avant de connecter le chapitre. Les brouillons de chaque branche sont conservés lorsque tu en changes.

        
        

          L’éditeur travaille directement sur strings/strings_chapitre_N.json dans le clone Git.
          Publier fusionne les changements, crée un commit et envoie ce fichier sur la branche choisie.
          La copie dans le jeu est désactivée par défaut. Si tu l’actives, chaque sauvegarde ou synchronisation
          met aussi à jour lang/lang_fr.json, avec une sauvegarde de son contenu précédent.
        

        

          Configurer l’accès GitHub et l’auteur des traductions
          
RUNEDELTA est privé : accepte d’abord l’invitation de l’équipe avec ton compte GitHub. Git doit être installé sur ce poste.

          
La connexion guidée utilise GitHub CLI et configure Git pour GitHub sur ce poste. Les identifiants sont gérés par GitHub CLI ; DELTATRANSLATE ne demande ni ne conserve de token. Avec des identifiants Git déjà configurés, utilise directement « Vérifier l’accès ».

          

            
            
            
            
            
          

          
L’accès en lecture suffit pour installer et récupérer. La publication exige aussi les droits d’écriture.

          

          
          
          
          
Après une connexion guidée, ton compte et son adresse GitHub privée sont utilisés. L’auteur est configuré uniquement dans le clone Runedelta ; ton identité Git globale reste inchangée.

        

        
« Récupérer » fusionne les traductions distantes avec ton travail local sans commit ni publication. Une copie du catalogue existant est conservée avant tout remplacement, même si les backups courants sont désactivés.
