Cette reconstruction de **DELTATRANSLATE 1.2.0** remplace les fichiers précédents des deux éditions.

- Vérification automatique des mises à jour à chaque démarrage et à la réouverture de la fenêtre.
- Une fenêtre signale les nouvelles versions, avec le choix de télécharger ou de remettre à plus tard. Le bouton de mise à jour reste disponible.
- Sur macOS et les formats sans installation automatique, la notification ouvre les téléchargements pour remplacer manuellement l’application.
- Les mises à jour automatiques conservent l’édition choisie, Standard ou Avec-Git.

Les deux éditions permettent de traduire localement sans compte GitHub. L’édition Standard nécessite une installation séparée de Git et GitHub CLI pour Runedelta. L’édition Avec-Git les inclut et propose **Se connecter à GitHub** dans Runedelta.

**Si vous avez déjà la 1.2.0, téléchargez cette reconstruction manuellement une fois.** Le numéro reste 1.2.0 : les anciennes installations ne peuvent pas distinguer cette reconstruction d’une version déjà à jour. Les prochaines versions supérieures seront signalées au démarrage.

Aucun fichier du jeu n’est fourni. Les traductions et préférences restent conservées. Le téléchargement et le redémarrage nécessitent votre action.
